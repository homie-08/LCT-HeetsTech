# Модели

По условиям кейса можно использовать только модели с открытыми весами под
Apache 2.0 или MIT и не крупнее 35B параметров. Проект этому следует
буквально: в коде нет ни одного провайдера с закрытыми весами, а модель
подключается через OpenAI-совместимый endpoint — тот, что поднимают Ollama,
vLLM или Inference API организаторов.

## Что делает модель и что не делает

| Задача | Промпт | Схема ответа | Если модели нет |
|---|---|---|---|
| План истории: состав слайдов, заголовки-выводы, тезисы, ссылки на блоки | [`backend/prompts/planner.md`](backend/prompts/planner.md) | `deck_plan` | эвристический планировщик по заголовкам и абзацам |
| Текст слайдов по краткому брифу, когда контент-пакета нет: структура под назначение (фича, продукт, проект, отчёт) и тезисы | [`writer.md`](backend/prompts/writer.md) | `deck_plan` | нет — без модели бриф не превратить в слайды, сборка так и говорит |
| Сокращение подписи под лимит слота (по одной и пакетом) | [`shortener.md`](backend/prompts/shortener.md), [`shortener-batch.md`](backend/prompts/shortener-batch.md) | `shorten`, `shorten_many` | обрезка по границе предложения и слова |
| Контекстуальный аудит: вывод ли в заголовке, о том ли слайд, связаны ли соседи, одна ли мысль | [`auditor.md`](backend/prompts/auditor.md) | `audit` | проверки помечаются «пропущено: модель не подключена» |

Модель **не** решает, какой макет взять, где стоит текст и какого он кегля,
какие цвета и шрифты у колоды. Это считается кодом по дизайн-системе шаблона и
метрикам шрифтов — так вёрстка остаётся воспроизводимой и проверяемой.

Каждый ответ проверяется по JSON-схеме; при расхождении запрос повторяется
с текстом ошибки. Ответы кешируются по хешу промпта, схемы и сообщений
(`.cache/llm`), поэтому правка промпта автоматически обесценивает старые
ответы, а повторная сборка того же контента не ходит в сеть.

Дополнительные страховки от особенностей маленьких моделей:

- план, который не опирается на слова документа (совпадение значимых слов
  ниже 55 %), отбрасывается в пользу эвристики — модель написала «вообще»;
- выдуманные контакты (почта, телефон, сайт, которых нет в исходнике)
  вычищаются из плана;
- сокращение, в котором появились числа или латинские слова, которых не было
  в исходнике, не принимается;
- пустой заголовок слайда заменяется первым тезисом;
- в режиме автора (по брифу) числа, которых нет в брифе, вырезаются из
  тезисов, выдуманный слайд с контактами убирается, повторы заголовков
  разводятся — модель 4B нарушает запрет на цифры даже с примером в промпте;
- цифры на слайдах сверяются с исходными материалами аудитом
  (`unsourced_number`) — так была поймана подмена «1 день» на «0.5 дней».

## Проверенная конфигурация

| | |
|---|---|
| Модель | **Qwen3-4B-Instruct** (`qwen3:4b-instruct` в Ollama) |
| Лицензия | Apache 2.0 |
| Веса | [huggingface.co/Qwen/Qwen3-4B-Instruct-2507](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507) |
| Размер | 4B параметров; квантованная Q4_K_M — около 2,5 ГБ |
| Железо | ноутбучная видеокарта с 4–6 ГБ памяти или CPU с 8 ГБ ОЗУ (медленнее); вся разработка и демо идут на ноутбуке без внешнего API |
| Скорость | план 12 слайдов — 20–60 с; полный аудит колоды — 20–40 с; три варианта колоды с моделью — 2–3 минуты |
| Structured outputs | `json_schema` (Ollama поддерживает); при отказе сервера — `json_object`, затем схема в промпте |

Запуск локально:

```bash
ollama pull qwen3:4b-instruct
```

`.env` (шаблон — [`.env.example`](.env.example)):

```
SD_LLM_PROVIDER=openai_compatible
SD_LLM_BASE_URL=http://127.0.0.1:11434/v1
SD_LLM_API_KEY=ollama
SD_LLM_MODEL=qwen3:4b-instruct
SD_LLM_TIMEOUT=300
SD_LLM_BUDGET_S=150
```

Переключение на API организаторов — правка трёх строк (`BASE_URL`, `API_KEY`,
`MODEL`), код не меняется.

## Бюджет времени

ТЗ отводит на колоду до пяти минут. Модель получает из них не больше
`SD_LLM_BUDGET_S` секунд (по умолчанию 150) на одну сборку: планирование,
сокращения и контекстуальный аудит идут из одного бюджета. Когда он исчерпан,
сборка продолжается без модели, а в отчёте это видно: пропущенные проверки
подписаны причиной, план помечен как эвристический. Так колода всегда
получается, а не зависает на медленном endpoint'е.

## Другие подходящие модели

Всё, что отдаёт JSON по схеме через OpenAI-совместимый endpoint, подключается
той же правкой `.env`. Из открытых моделей в лимите 35B:

| Модель | Лицензия | Зачем |
|---|---|---|
| Qwen3-8B / Qwen3-14B / Qwen3-32B | Apache 2.0 | тот же формат ответов, точнее заголовки и связки между слайдами |
| Mistral-Small-3 (24B) | Apache 2.0 | сильный русский, хорошо держит схему |

Модели под другими лицензиями (Llama, Gemma) в список не входят: ТЗ называет
Apache 2.0 и MIT.

Промпты написаны без привязки к модели: инструкции явные, поля схемы
названы по смыслу, примеры — в тексте промпта. При смене модели достаточно
прогнать `python -m sd build … --variant all` на демо-контенте и посмотреть
отчёт аудита.

## Что модель не увидит

Модели отдаются только текст блоков и текст готовых слайдов. Картинки,
шаблон, координаты и цвета к ней не уходят — не потому, что это секрет, а
потому, что за них отвечает код, и запрос без них короче и дешевле.
