# Handoff: VK Slides — генератор презентаций

## Обзор
Тёмный минималистичный веб-интерфейс ИИ-генератора презентаций в стилистике Kimi с палитрой VK Tech: пользователь описывает тему (или прикрепляет файл), получает структуру будущей презентации, подтверждает её и просматривает сгенерированные слайды с возможностью экспорта в .pptx.

## О файлах дизайна
Файлы в этом пакете — **дизайн-референсы, созданные в HTML** (прототип `VK Slides v2.dc.html` + рантайм `support.js`). Это не production-код. Задача разработчика — **воссоздать этот дизайн в целевом стеке проекта** (React, Vue, Svelte и т.п.) по его принятым паттернам; если стека ещё нет — выбрать подходящий фреймворк и реализовать дизайн в нём. Открыть прототип: положить оба файла рядом и открыть `VK Slides v2.dc.html` в браузере.

## Степень проработки
**High-fidelity**: финальные цвета, типографика, отступы, состояния и анимации. Верстать пиксель-в-пиксель по значениям ниже.

## Взаимодействия и поведение
- Enter в textarea (без Shift) = клик по кнопке отправки; пустой ввод не отправляется.
- Кнопка отправки меняет цвет мгновенно при вводе первого символа.
- Скрепка добавляет мок-файл «стратегия-2027.pdf» (в реальном приложении — файловый диалог, PDF/DOCX).
- Выбор шаблона: клик по карточке или циклический клик по чипу; выбранное имя дублируется в чипе и в футере структуры.
- «Изменить запрос» возвращает на главный с сохранённым текстом; «назад» из деки сбрасывает всё.
- Все hover-состояния: граница `rgba(77,159,255,0.55)` + текст/иконка `#4D9FFF` (ghost) или осветление заливки до `#1E85FF` (primary).

## Состояние (модель)
```
screen: 'home' | 'outline' | 'deck'
prompt: string            // текст запроса
file: string | null       // имя прикреплённого файла
countN: number            // количество слайдов, кламп 3–30, по умолчанию 8
tpl: 0..5                 // индекс выбранного шаблона
outlineN: 0..8            // сколько пунктов структуры уже показано (таймер 380мс)
slide: number             // индекс текущего слайда
sideOpen: boolean         // видимость сайдбара
toast: string             // текст всплывашки ('' = скрыта)
```
Данные: массив пунктов структуры (8), массив слайдов (8, поля: variant, kicker, title, sub/bullets/steps/big+small), список недавних (4), список шаблонов (6).
