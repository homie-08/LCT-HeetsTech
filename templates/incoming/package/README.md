# Пакет шаблонов презентаций (18 стилей)

18 готовых колод по 12–14 слайдов, 1920×1080. На их основе автоматически собираются новые презентации: берёте колоду нужного стиля, меняете тексты/цифры, добавляете-убираете слайды из готового набора макетов.

## Состав пакета

- `01…18 *.dc.html` — колоды-шаблоны (открываются в браузере; работают рядом с `deck-stage.js` и `support.js`)
- `00 Обзор.dc.html` — индекс всех стилей с палитрами
- `templates.json` — машиночитаемая спецификация: палитра, шрифты, приёмы каждого шаблона
- `deck-stage.js` — движок слайдов (масштабирование, навигация, печать в PDF)
- `support.js` — рантайм формата .dc.html
- `_ds/organic-…/` — стили дизайн-системы Organic (нужны только шаблону 01)
- `examples/` — исходные PPTX-примеры, по которым выверены контейнеры, диаграммы и стрелки

## Устройство шаблона

Каждый слайд — `<section data-label="…">` внутри `<x-import …deck-stage…>`; все стили inline, классов нет. Набор макетов одинаковый во всех колодах (обложка, содержание, разделитель, три карточки, большая цифра, таймлайн, таблица, цитата, две колонки, «задел» с нумерованными рядами и шевронами, сравнение с ✓/—, KPI-сетка, финал) — новые слайды собираются копированием ближайшей секции.

## Правила автосборки

1. Кегль не ниже 24px; заголовки слайдов 64–96px, обложка 110–180px.
2. Поля слайда: 80–100px по вертикали, 100–140px по горизонтали.
3. Только шрифты с кириллицей (все подключения Google Fonts уже в `<helmet>` каждой колоды).
4. Один акцентный цвет (+1–2 вспомогательных) на колоду; значения — в `templates.json`.
5. Прочерки «—» в таблицах — приглушённым цветом, словесные значения — читаемым muted-цветом колоды.
6. Иконки — линейные (Lucide-стиль), stroke 2–2.75, внутри цветной плашки (круг/квадрат/пилюля — по стилю колоды).

## Диаграммы (как в примерах)

Донаты, арки и сегменты — кольцевые секторы со скруглёнными углами. Генератор SVG-пути:

```js
const P=(cx,cy,ρ,a)=>{const t=a*Math.PI/180;return (cx+ρ*Math.cos(t)).toFixed(1)+' '+(cy+ρ*Math.sin(t)).toFixed(1)};
function sector(cx,cy,Ro,Ri,a1,a2,c,fill){ // c — радиус скругления угла (~7 при Ro=80, Ri=45)
  const go=c/Ro*180/Math.PI, gi=c/Ri*180/Math.PI, span=a2-a1;
  const lf=(span-2*go)>180?1:0, lfi=(span-2*gi)>180?1:0;
  const d=['M'+P(cx,cy,Ro,a1+go),`A${Ro} ${Ro} 0 ${lf} 1 `+P(cx,cy,Ro,a2-go),`A${c} ${c} 0 0 1 `+P(cx,cy,Ro-c,a2),
    'L'+P(cx,cy,Ri+c,a2),`A${c} ${c} 0 0 1 `+P(cx,cy,Ri,a2-gi),`A${Ri} ${Ri} 0 ${lfi} 0 `+P(cx,cy,Ri,a1+gi),
    `A${c} ${c} 0 0 1 `+P(cx,cy,Ri+c,a1),'L'+P(cx,cy,Ro-c,a1),`A${c} ${c} 0 0 1 `+P(cx,cy,Ro,a1+go),'Z'].join(' ');
  return `<path d="${d}" fill="${fill}"/>`;
}
// Квадрант-донат: sector(100,100,80,45, -87,-3, 7, цвет) и далее с шагом 90° (зазор 6°)
```

Прочие приёмы:
- **Шевроны-баннеры**: `clip-path:polygon(0 0,100% 0,100% 78%,50% 100%,0 78%)` (вниз) и `polygon(0 0,calc(100% - 50px) 0,100% 50%,calc(100% - 50px) 100%,0 100%,50px 50%)` (лента вправо).
- **Лепестки к центру**: квадрат с `border-radius:50% 50% 10% 50%`, повёрнутый так, чтобы «острый» угол смотрел в общий центр; три штуки под 120°, зазор — рамкой цвета фона.
- **Орбита**: круг-стрих + узлы-круги с иконками на радиусе.
- **Стрелки-коннекторы**: двойные шевроны `<path d="m7 5 7 7-7 7"/><path d="m14 5 7 7-7 7"/>`.
- **Календарный план-зигзаг**: центральная колонка с квадратными узлами 1/2, тексты попеременно слева/справа.

## Экспорт

Каждая колода печатается в PDF из браузера (один слайд — одна страница) и экспортируется в PPTX (редактируемый) — обращайтесь к ассистенту.
