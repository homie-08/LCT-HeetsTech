# 08. Видео-демо

ТЗ (п. 6, промежуточный этап) просит «видео-демо — до 7 минут: запись экрана
без монтажных склеек или живой прогон». Здесь и то и другое сразу: запись
сделана с живого прогона, непрерывно, без склеек и ускорений.

## Что записано

| Файл | Длительность | Что показано |
|---|---|---|
| `data/out/видео/Демо-прогон (6-37).mp4` | 6:37 | Основная запись под лимит ТЗ: шаблон организаторов → бриф с контент-пакетом → структура → три варианта → слайды → аудит с выбором находок → скачивание `.pptx` |
| `data/out/видео/Демо-прогон полный (10-47).mp4` | 10:47 | Тот же сценарий целиком, включая ремонт выбранных слайдов и пересборку; за лимит выходит, держим как доказательство полного цикла |

Исходники в `.webm` лежат рядом (`data/out/demo`, `data/out/demo-short`) —
mp4 получен перекладкой кадр в кадр (`scripts/webm_to_mp4.py`), без обрезки.

## Как записано

```bash
# сервер уже поднят: run.cmd
python scripts/demo_video.py --out data/out/demo --slides 8 --skip-repair
```

[`scripts/demo_video.py`](../scripts/demo_video.py) ведёт настоящий Chrome
через Playwright и пишет видео страницы средствами самого Playwright. Каждый
шаг объявляется в консоли с отметкой времени — по журналу видно, сколько
заняла модель, а сколько сборка.

Честные оговорки, чтобы на защите не было сюрпризов:

- **Курсор нарисован скриптом.** В записи страницы системного курсора нет,
  поэтому поверх рисуется точка и круг на клике — это единственное, чего нет
  в самом интерфейсе. Отключается удалением `CURSOR` из скрипта.
- **Звука нет.** Если нужна озвучка, её можно наговорить поверх — это не
  монтажная склейка; текст для неё — [`05-demo-script.md`](05-demo-script.md).
- **Полный сценарий в 7 минут не укладывается** на этой машине: локальная
  Qwen3-4B идёт 21 ток/с (в видеопамять RTX 3050 помещается 2,3 ГБ из 3,5 —
  остальное считает процессор). Из 6:37 записи модель занимает около 5:40:
  план истории 1:45, сборка трёх вариантов 3:54. Поэтому в короткую запись не
  вошёл ремонт по выбору — он есть в полной. На инференсе организаторов
  (Qwen 27B) тот же сценарий уложится с запасом.
