# Промпты и конфиги агентов

Здесь лежит всё, что уходит модели. В коде промптов нет — только загрузка
из этих файлов (`sd/llm/prompts.py`). Так требует ТЗ, и так удобнее: правка
формулировки — это правка текста, а не релиз кода.

| Файл | Кто использует | Схема ответа |
|---|---|---|
| `planner.md` | `sd/plan/storyline.py` — план истории по контенту | `deck_plan` |
| `writer.md` | `sd/plan/storyline.py` — план и текст слайдов по краткому брифу, когда контент-пакета нет | `deck_plan` |
| `auditor.md` | `sd/qa/audit.py` — контекстуальный аудит готовой колоды | `audit` |
| `shortener.md` | `sd/fit/shorten.py` — одна подпись под лимит | `shorten` |
| `shortener-batch.md` | `sd/fit/shorten.py` — пакет подписей за один запрос | `shorten_many` |

## Формат

Файл — markdown с шапкой между `---`:

- `id` — имя, по которому промпт загружается;
- `version` — целое, растёт при любой правке текста;
- `purpose`, `schema`, `model` — назначение, схема ответа, на чём проверялось;
- `history` — что менялось и когда.

Тело после шапки уходит модели как есть.

## Версионирование

Версия каждого промпта попадает в отчёт сборки и в `/api/status` — по
готовой презентации видно, какими версиями агентов она собрана. Кеш ответов
модели считается от текста промпта, поэтому правка автоматически
обесценивает старые ответы.
